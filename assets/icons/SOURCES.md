# Icon sources

Technology and LinkedIn icons: [Devicon](https://github.com/devicons/devicon/tree/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6), MIT license; see LICENSE-devicon.txt.

Generic SQL database and Instagram icons: [Font Awesome Free](https://github.com/FortAwesome/Font-Awesome/tree/14c65a3747d0f3b751f15831fc719236aea8729d), icons under CC BY 4.0; see LICENSE-fontawesome.txt. Copyright Fonticons, Inc.

Express uses neutral grey. SQL uses blue (#3b82f6), and Instagram uses pink (#e4405f), with explicit path fills for visibility when embedded as images. Instagram's viewBox is cropped to its square artwork to make better use of the small icon size. Other icon artwork is unchanged. Brand marks belong to their respective owners.

Icons are stored locally so the profile does not depend on an external icon service.
